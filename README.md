# 旅遊小帳

手機優先的靜態 PWA，支援日圓／韓元與台幣雙向換算、最新可用參考匯率、手動匯率、算式、記帳、加總與平分。

## 功能
- 每次開啟預設日圓；韓元各自保存匯率與手動模式。
- 消費保存原幣與歷史匯率；混合幣別以台幣統計。
- 深色／淺色／跟隨系統。
- JSON 備份與還原、CSV 匯出、備份確認後清除全部資料。
- 手機大按鈕與數字鍵盤、Service Worker 離線程式快取。

## 部署
把所有檔案放在同一資料夾，上傳到 HTTPS 靜態主機即可，支援根目錄與子目錄。
不需要 npm、資料庫或後端。也可啟用 GitHub Pages，以 main 分支根目錄部署。
本專案本身不會自動啟用 GitHub Pages 或更動儲存庫設定。
本機可用 `python -m http.server 8080`，開啟 `http://localhost:8080`。
直接開啟 HTML 不支援完整 PWA。手機連到區網 HTTP IP 不是 localhost。

## 安裝與離線
支援的瀏覽器可透過安裝提示或選單安裝；iPhone 可從 Safari 分享選單加入主畫面。
本版使用 SVG manifest 圖示；不同系統／瀏覽器對安裝圖示支援有差異，不保證各平台呈現一致。
首次必須連線，並等待設定頁顯示離線快取已就緒。更新匯率仍需網路。
更新程式後請修改 sw.js 中的 CACHE 版號。新版不強制接管，關閉所有 App 視窗再開啟以套用。

## 資料
資料儲存在目前瀏覽器，不跨裝置同步。不要同時開多個視窗編輯；不提供衝突合併。
使用 travel-pocket-v2 格式；支援同網址上一版 japan-pocket-calculator-v1 自動遷移。
JSON 支援 version 1 與 version 2；匯入是取代，不是合併。換網址請使用 JSON 遷移。
清除只移除本工具新舊兩個 key，不清除其他網站資料，不移除離線程式或解除安裝。
瀏覽器無法確認下載真的儲存成功，清除前務必親自檢查 JSON。
一人份額採精確除法、顯示至小數第二位；整數日圓／韓元分配提示僅供收款參考。

## 匯率
Frankfurter API `/v2/rate/JPY/TWD`、`/v2/rate/KRW/TWD`。
僅為最新可用參考資料，不是秒級報價或銀行／信用卡成交價。
失敗時使用已存匯率；無資料則要求手動設定，不使用假匯率。

## 驗收
1. 日圓手動 0.21、輸入 1000：應顯示 NT$210。
2. 韓元手動 0.025、輸入 10000：應顯示 NT$250。
3. 各記一筆，合計應為 NT$460；更新匯率不應改動舊帳。
4. 匯出 JSON，檢查下載，清除，應無帳目並回復日圓；再還原備份。
5. 深淺色與跟隨系統、離線重開、PWA 安裝，需在實際裝置測試。
